# SeqPro 0.2.0 中文发布摘要

SeqPro 0.2.0 是项目的首次公开版本，提供可复用的 C++17 序列库，用于标准 FAI 构建与验证，
以及基于只读 mmap 的未压缩 FASTA 随机访问。

## 主要能力

- 生成与 Samtools/HTSlib 互操作的标准五列 FAI。
- 使用独立、版本化的 XXH3-128 metadata sidecar，不改变 FAI。
- `IndexedFasta` 和 `FastaSequenceView` 提供 O(1) ID 访问、平均 O(1) 名称查询、严格越界
  检查、调用方缓冲区读取、流式输出和零复制物理 chunk。
- 同一个不可变映射支持无锁 const 并发读取。
- 可选且独立构建的 `SeqPro::sequence_text` 组件支持 excluded interval、active run、三套
  坐标、tagged 控制字节位置、generation 绑定更新和显式文本物化。
- 可迁移的 CMake package 支持 add_subdirectory、FetchContent 和
  `find_package(SeqPro 0.2 CONFIG REQUIRED)`。
- 首发验证平台为 x86_64 Linux/WSL，最低 GCC 9、Clang 10 和 CMake 3.20。

## 兼容性与范围

在相同 x86_64 平台、编译器 ABI 和 C++ runtime ABI 下，0.2.x 计划保持补丁版本兼容。不同
小版本、libc++/libstdc++ 边界或不同 `_GLIBCXX_USE_CXX11_ABI` 配置之间不承诺二进制兼容。

SequenceText 不改变标准 FAI 或 metadata schema 1，并且始终默认关闭。本版本不包含
gzip/BGZF、FASTQ、远程存储、原生 Windows/macOS、AArch64 发布承诺、区间文件解析、后缀
数组/FM-index 算法或通用 Linux 预编译二进制。
