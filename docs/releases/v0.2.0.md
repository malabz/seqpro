# SeqPro 0.2.0

SeqPro 0.2.0 is the project's first public release. It provides a reusable C++17 library for
standard FAI construction, validation, and immutable mmap-backed random access to uncompressed
FASTA files.

## Highlights

- Standard five-column FAI output interoperable with Samtools/HTSlib.
- Versioned XXH3-128 metadata sidecar without modifying the FAI.
- `IndexedFasta` and `FastaSequenceView` with O(1) ID access, average O(1) name lookup, strict
  bounds checks, caller-buffer reads, streaming output, and zero-copy physical chunks.
- Lock-free concurrent const reads over one immutable mapping.
- Optional, separately built `SeqPro::sequence_text` component for excluded intervals,
  active-run layouts, three coordinate systems, tagged control-byte locations, generation-bound
  updates, and explicit text materialization.
- Relocatable CMake packages supporting add_subdirectory, FetchContent, and
  `find_package(SeqPro 0.2 CONFIG REQUIRED)`.
- x86_64 Linux/WSL release validation with GCC 9+, Clang 10+, CMake 3.20+, sanitizers, fuzzing,
  Doxygen, symbol auditing, ABI checks, and reproducible source archives.

No compatibility aliases are provided because these names were frozen before the first public tag.

## Compatibility

The 0.2.x SONAME and package policy permit compatible patch updates on the same x86_64 platform,
compiler ABI, and C++ runtime ABI. SeqPro does not promise binary compatibility across minor
versions, libc++/libstdc++ boundaries, or different `_GLIBCXX_USE_CXX11_ABI` configurations.

The standard FAI and metadata schema 1 are unchanged by SequenceText. The optional component remains
disabled unless explicitly requested.

## Known scope

This release supports uncompressed FASTA on x86_64 Linux/WSL. It does not provide gzip/BGZF, FASTQ,
remote storage, native Windows/macOS, AArch64 guarantees, interval-file parsers, suffix-array or
FM-index algorithms, or generic precompiled Linux binaries.
